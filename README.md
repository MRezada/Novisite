# نووی‌سافت — وب‌سایت شرکت + پلتفرم سازمانی Novi One + پنل مدیریت


## تغییرات رابط نسخه 3.2

- تیتر Hero جمع‌وجورتر و دارای حرکت بسیار ملایم چندلایه شده است.
- ویترین چرخان نرم‌افزارها در دسکتاپ بالاتر آمده تا هم‌زمان با پیام اصلی دیده شود.
- کارت‌های شناور متحرک برای Software Engineering و Business Intelligence به Hero اضافه شده‌اند.
- یک نوار متحرک تکنولوژی در Hero اضافه شده است.
- بخش فناوری به دو جریان متحرک «مهندسی نرم‌افزار» و «هوش تجاری و داده» تبدیل شده است.
- برای کاربران دارای prefers-reduced-motion تمام حرکت‌های جدید غیرفعال می‌شوند.

نسخه‌ی بازطراحی‌شده‌ی سایت نووی‌سافت با **Next.js 16 + React 19 + TypeScript**، رابط کاملاً فارسی/RTL، پنل مدیریت فایل‌محور و ساختار سئوی فنی و محتوایی.

این نسخه علاوه بر سایت B2B، معماری محصول **Novi One** را معرفی می‌کند: یک فضای کاری سازمانی مشترک که چهار ماژول «انبار و مدیریت قطعات»، «هوش تجاری»، «مدیریت و پشتیبانی IT» و «تیکتینگ/میز خدمت» روی آن فعال می‌شوند. هر ماژول مستقل قابل خرید است اما هویت، کاربران، سطح دسترسی، اعلان‌ها و زیرساخت پایه بین آن‌ها مشترک می‌ماند.


## معماری پیشنهادی Novi One

- **Core Platform:** حساب سازمانی، کاربران و نقش‌ها، Audit Log، اعلان‌ها، تنظیمات مشترک، API و آماده‌سازی برای SSO
- **Novi Inventory:** انبار، قطعات، ورود/خروج، انتقال، حداقل موجودی و گزارش
- **Novi BI:** KPI، داشبورد مدیریتی، گزارش تعاملی و اتصال به منابع داده
- **Novi IT:** دارایی IT، پایش شبکه و Endpoint، فضای ذخیره‌سازی و سلامت زیرساخت
- **Novi Desk:** تیکتینگ، صف، SLA، ارجاع کارشناسان، گزارش عملکرد و رضایت

مدل فروش پیشنهادی این است که با خرید هر ماژول، هسته پلتفرم نیز فعال شود. مشتری می‌تواند بعداً ماژول جدید را روی همان حساب سازمانی اضافه کند. در صفحه `/products` یک Configurator تعاملی برای انتخاب ماژول‌ها و ارسال درخواست دمو اضافه شده است.

تصویر واقعی داشبورد انبار در `public/screens/inventory-dashboard.png` قرار گرفته و برای سه ماژول دیگر پیش‌نمایش رابط با CSS ساخته شده تا تا زمان قرار دادن اسکرین‌شات‌های نهایی، ساختار صفحه کامل بماند.

## مهم‌ترین تغییرات نسخه جدید

- صفحه اصلی کامل‌تر با معرفی مستقیم Novi One و چهار ماژول سازمانی، سپس خدمات توسعه، پروژه‌ها، راه‌حل‌ها و CTA
- پالت رنگی جدید با Navy/Blue/Cyan سازمانی، کنتراست آرام‌تر و هماهنگی بیشتر با رابط نرم‌افزارهای واقعی
- صفحه پلتفرم کامل با معماری Core + Modules، نمایش Workspace، ارتباط بین ماژول‌ها و Configurator خرید
- ۴ صفحه محصول عمیق و SEOمحور برای انبارداری، BI، مدیریت IT و تیکتینگ، در کنار ۶ صفحه خدمات توسعه
- هاب محتوایی سئو با مقاله‌های evergreen درباره نرم‌افزار سفارشی، هزینه توسعه، MVP، وب‌اپ و RAG/AI
- فرم تماس کامل‌تر با شرکت، بودجه و بازه زمانی؛ نمایش همان اطلاعات در پنل مدیریت
- JSON-LD تکمیل‌شده برای Organization، WebSite، WebPage، ItemList، Breadcrumb، Service، SoftwareApplication، Article و FAQ
- canonical، Open Graph، Twitter Card، robots، sitemap، feed، metadata یکتا و لینک‌سازی داخلی
- مهاجرت نرم تنظیمات صفحه اصلی: تنظیمات ذخیره‌شده‌ی نسخه قبلی حفظ می‌شوند و سکشن‌های جدید به ساختار اضافه می‌شوند

## اجرا در محیط توسعه

```bash
npm install
cp .env.example .env.local
npm run dev
```

سپس سایت روی `http://localhost:3000` و پنل مدیریت روی `http://localhost:3000/admin` در دسترس است.

در فایل `.env.local` حداقل این موارد را تنظیم کنید:

```env
ADMIN_PASSWORD=یک-رمز-قوی-و-منحصربه‌فرد
ADMIN_SECRET=یک-رشته-تصادفی-طولانی
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> نسخه‌ی تحویلی فعلی برای ادامه‌ی تست همان رمز درخواستی قبلی را در `.env.local` دارد. **پیش از انتشار عمومی حتماً آن را تغییر دهید.**

## ساختار SEO

- برای صفحه‌های اصلی و Detailها عنوان، توضیح، canonical، Open Graph و Twitter metadata تولید می‌شود.
- صفحه‌ی مستقل هر خدمت برای پوشش intentهای مهم مثل «توسعه نرم‌افزار سفارشی»، «طراحی وب اپلیکیشن»، «طراحی اپلیکیشن موبایل» و «هوش مصنوعی برای کسب‌وکار» وجود دارد.
- مقاله‌های evergreen برای ساخت Topic Cluster و لینک‌سازی داخلی به خدمات اضافه شده‌اند.
- داده‌ی ساختاریافته فقط از محتوای قابل مشاهده‌ی همان صفحات ساخته می‌شود.
- `sitemap.xml` به‌صورت پویا خدمات، پروژه‌ها، محصولات و مقاله‌های منتشرشده را پوشش می‌دهد.
- `/admin` و `/api` از ایندکس خارج شده‌اند.
- فونت Vazirmatn با `next/font` بهینه و پس از build توسط خود اپ ارائه می‌شود.
- `lang="fa"` و `dir="rtl"` در ریشه سند تنظیم شده‌اند.

### بعد از انتشار برای SEO

1. `siteUrl` را در پنل روی دامنه نهایی HTTPS بگذارید.
2. `https://your-domain.tld/sitemap.xml` را در Google Search Console ثبت کنید.
3. کد Search Console را از پنل وارد کنید.
4. پروژه‌ها، اعضای تیم، مشتریان و testimonialهای نمونه را با اطلاعات واقعی جایگزین کنید.
5. عنوان/توضیح هر پروژه و خدمت را با داده‌های واقعی کسب‌وکار بازبینی کنید.
6. تصاویر واقعی پروژه‌ها را WebP/AVIF و با ابعاد مناسب بارگذاری کنید.
7. Core Web Vitals و صفحات ایندکس‌شده را بعد از انتشار پایش کنید.

## استقرار روی VPS

به‌دلیل ذخیره‌ی داده‌ها و رسانه‌های پنل روی دیسک، این پروژه برای **VPS یا سرور Node.js با فضای پایدار** مناسب است و نباید بدون تغییر معماری ذخیره‌سازی روی محیط‌های serverless موقت استقرار یابد.

```bash
npm install
npm run build
npm start

# نمونه با PM2
pm2 start npm --name novisoft -- start
```

- پوشه‌ی `data/` یا مسیری که با `DATA_DIR` تعیین می‌کنید باید persistent باشد و از آن نسخه پشتیبان بگیرید.
- هنگام Deploy نسخه جدید، پوشه‌ی داده‌ی واقعی را حذف یا با seed جایگزین نکنید.
- سایت را پشت Nginx/Caddy با HTTPS اجرا کنید.
- در production برای `ADMIN_PASSWORD` رمز قوی و برای `ADMIN_SECRET` مقدار تصادفی بلند استفاده کنید.

## ساختار پروژه

```text
src/lib/         داده، DB فایل‌محور، احراز هویت، SEO، Markdown و seed
src/admin/       فرم‌ها و schema پنل مدیریت
src/sections/    سکشن‌های مستقل صفحه اصلی
src/components/  اجزای رابط و فرم‌ها
src/app/(site)/  صفحات عمومی
src/app/admin/   پنل مدیریت
src/app/api/     APIها
```

## نکته مهم درباره محتوای نمونه

محتوای اولیه‌ی پروژه‌ها، محصولات، اعضای تیم و برخی اطلاعات برند **نمونه** است. برای جلوگیری از ادعاهای ساختگی، در نسخه جدید آمار جعلی یا لوگوی مشتری ساختگی اضافه نشده است. پیش از انتشار عمومی، این بخش‌ها را از پنل با اطلاعات واقعی نووی‌سافت جایگزین کنید.
